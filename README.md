# Mi Proyecto Web — Módulo 2

## Descripción

Proyecto académico para desarrollar una página de servicios, mejorar el diseño web y documentar el trabajo colaborativo mediante GitHub.

## Tecnologías
- HTML5
- CSS3
- GitHub

## Archivos
- `index.html`: página principal.
- `servicios.html`: página de servicios.
- `contacto.html`: página de contacto.
- `styles.css`: estilos compartidos.
- `.gitignore`: archivos y carpetas que Git debe ignorar.

## Objetivos de aprendizaje
1. Organizar un repositorio y mantener un historial de cambios.
2. Crear commits con mensajes claros.
3. Trabajar con ramas de características.
4. Provocar y resolver un conflicto de combinación.
5. Abrir y revisar un pull request.
6. Publicar el sitio con GitHub Pages.

## Publicar con GitHub Pages
1. En el repositorio, abre **Settings**.
2. En el menú lateral, selecciona **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`.
5. Pulsa **Save** y espera a que GitHub publique el sitio.
